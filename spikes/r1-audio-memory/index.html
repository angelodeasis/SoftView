SoftView Spike R1 — decodeAudioData memory & scaling

Disposable experiment. Measures how decoded PCM memory scales with duration / channels / sample rate, how fast decode is, and whether a decode-time downsample is possible. Nothing is uploaded. Pick a local MP3/MP4/M4A (or use the fixtures in this folder). For heap deltas to appear, run Chrome with --enable-precise-memory-info.
